# 얼반크랙 동호회 회칙

얼반크랙 동호회의 회칙을 열람하고 개정 이력을 관리하는 저장소입니다.

- 📜 **[현행 회칙 보기](bylaws.md)** — 2025. 11. 15. 일부개정
- 🗂️ **[개정 연혁](HISTORY.md)** — 지금까지의 개정 내용과 버전별 전문

## 읽는 법

회칙은 대한민국 법령 표기 방식을 따릅니다.

| 표기 | 뜻 |
|---|---|
| **제1조(명칭)** | 조. 괄호 안은 조의 제목 |
| ① ② ③ | 항. 조 안의 독립된 문장 |
| 1. 2. 3. | 호. 조나 항 아래에 열거한 항목 |
| `<개정 2024. 11. 16.>` | 그 날짜에 내용이 바뀐 부분 |
| `<신설 2024. 11. 16.>` | 그 날짜에 새로 생긴 부분 |

## 예전 회칙 보기

- **특정 시점의 회칙 전문:** [개정 연혁](HISTORY.md)의 태그 링크를 누르거나, 상단의 브랜치 선택 메뉴에서 **Tags** → 날짜를 고릅니다.
- **무엇이 바뀌었는지:** `회칙.md`를 연 뒤 오른쪽 위 **History**를 누르면 개정별로 바뀐 줄이 빨강(삭제)·초록(추가)으로 표시됩니다.
- **이 문장은 언제 바뀌었나:** `회칙.md`에서 **Blame**을 누르면 줄마다 마지막으로 바뀐 개정이 표시됩니다.

## 회칙 개정 절차

1. **안건 제안** — 누구나 [Issues](../../issues)에 개정 제안을 올릴 수 있습니다. (GitHub 계정 필요)
2. **개정안 작성** — 총무가 브랜치를 만들어 `회칙.md`를 수정하고 Pull Request를 엽니다. 바뀐 부분이 비교 화면으로 표시되므로 총회 전에 회원들이 미리 확인할 수 있습니다.
3. **총회 의결** — 정기총회 또는 임시총회에서 의결합니다(제10조·제11조·제12조).
4. **반영** — 의결된 개정안만 병합합니다. 바뀐 조·항·호 끝에 `<개정 YYYY. M. D.>` 표시를 달고, 문서 머리의 `[시행 …] [일부개정 …]`과 [HISTORY.md](HISTORY.md)를 갱신한 뒤 날짜 태그(예: `2026-11-21`)를 붙입니다.

커밋 메시지 예: `회칙 일부개정: 2026년 정기총회(2026. 11. 21.) 의결`
